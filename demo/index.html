One asset, every size

Each bundle carries 16, 32 and 64 px renders at different levels of detail. The component picks the one that fits, like srcset. It never scales a big sprite down.

Sprites can sit inline in text too like an emoji, using the 16px icon render.

A character with a mind of its own

This goose's bundle carries a small state machine and two extra skins. The page only sets a speed; the character chooses idle, walk or run, switches gait without breaking stride, stops on a footstep, fidgets when bored, hacks while you hover it and honks when clicked.
