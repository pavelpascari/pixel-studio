Pixel Studio

Describe a character as JSON; the engine draws it as pixel art at every size, with realistic motion; one tag plays it on any web page, where it can even walk around your layout. Every example on these pages is live: the code under each one is exactly what runs.

Click the goose: its bundle carries a small state machine, so it honks; hover it and it starts hacking.

How it fits together

  1. Write a character as JSON: materials, parts with shapes, animations. Start from a figure (goose, human, dog, chibi, blob) and its motion models do the walking, jumping and climbing. Writing a character
  2. Bake a bundle: one JSON file with sprite sheets at 16, 32 and 64 px plus events, attachment points and the foot line. node bin/pixel.mjs bundle goose.json. Bundles
  3. Play it with <pixel-sprite>, drive it with a state machine, move it with the shared clock, or let it loose on the page with <pixel-stage>.
