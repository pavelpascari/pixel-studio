Characters on the page

<pixel-stage> turns your layout into a little world. Mark elements as surfaces, walls and hiding spots; characters walk along them, drop and jump between them, climb up, sit on edges and duck out of sight. They never block a click, and a tap shoos them.

Try it

Tap or click a character to shoo it; with a mouse, drag one to pick it up and throw it. This page hides the stage's own pause button (controls="none") and its floor; the full demo page has both.

Staying in sight

Give a character keep-in-view and it follows the reader: after a scroll settles, it runs back if it is close (at 2.5× speed, feet still planted), or drops in from the top of the screen onto a visible surface. The stage also reports scroll speed, so a page can react to fast scrolling. Try it on the demo page, which is long enough to scroll.

    <pixel-actor src="goose.bundle.json" size="64" keep-in-view></pixel-actor>

    stage.addEventListener('fastscroll', (e) => goose.say('wait for me!'));   // e.detail.speed in px/s
    goose.addEventListener('catchup', () => console.log('coming back'));
    goose.addEventListener('burst', (e) => console.log('rage taps', e.detail.count));   // tapping fast makes it panic

Scenes

A scene is a scripted moment written as data: who goes where, says what, and when. Steps run in order; together runs several at once, "async": true starts one without waiting, and waitFor pauses until something happens (a tap on a character, a click on a button). The cast is directed while it plays: characters wait for their next line instead of wandering off. Steps that cannot happen (no route, a tap that startles a character) are skipped, so readers poking at the characters never jam it. Press stage.playScene('#race') in the example above to play this one.

    {"cast": {"goose": "#st-goose", "pip": "#st-pip"}, "steps": [
      {"together": [{"actor": "goose", "goTo": "#st-low", "at": 0.2}, {"actor": "pip", "goTo": "#st-low", "at": 0.8}]},
      {"together": [{"actor": "goose", "face": "pip"}, {"actor": "pip", "face": "goose"}]},
      {"actor": "pip", "say": "Race you to the top?", "ms": 1600},
      {"actor": "goose", "say": "HONK", "ms": 900},
      {"together": [{"actor": "goose", "goTo": "#st-tall"}, {"actor": "pip", "goTo": "#st-mid"}]},
      {"actor": "goose", "say": "first!", "ms": 1400, "async": true},
      {"actor": "pip", "perform": "wave"},
      {"actor": "pip", "goTo": "#st-mid", "then": "sit"}
    ]}
  
    const run = stage.playScene('#race');      // an object, JSON text, or a <script type="application/json">
    await run.finished;                        // true at the end, false if run.stop() was called
    stage.addEventListener('sceneevent', (e) => console.log(e.detail.name));   // from {"emit": "…"} steps

    // The same orders, awaitable from code: true when done, false if impossible or interrupted.
    if (await goose.run('goTo', summit, { then: 'sit' })) await goose.say('made it');

Steps: goTo (a selector, a cast name, or a point; then, at), hideBehind, perform, say, face, shoo, wait, together, waitFor, emit. <pixel-stage scene="#intro"> plays one when the page loads. The full table is in docs/stage.md.

Triggers, carrying and leaving

Give a scene a trigger and mark its script data-pixel-scene: it plays by itself when that happens: a form submitted, a button clicked, a section scrolled into view ("visible"), a character tapped. Characters can pickUp any element (a copy rides at the beak or hand), drop it, exit by the side of the screen (delivering what they carry) and enter again. The demo page's newsletter form hands the goose a letter to post.

    {"cast": {"goose": "#goose"},
     "trigger": {"event": "submit", "on": "#signup", "preventDefault": true},
     "steps": [
       {"actor": "goose", "pickUp": "$trigger .letter"},
       {"actor": "goose", "exit": "right"},
       {"wait": 1800}, {"emit": "delivered"},
       {"actor": "goose", "enter": "right"},
       {"actor": "goose", "say": "delivered. HONK"}
     ]}

Marking up your page

attributemeaning
data-pixel-surfaceits top edge is a platform
data-pixel-climbableits sides are walls (its foot must rest on a platform)
data-pixel-percha favourite place to sit
data-pixel-hidea hiding spot (standing on a platform)
data-pixel-occludercharacters always pass behind it
data-pixel-avoidnever stand on or hide behind it

Scripting

    const goose = document.querySelector('pixel-actor');
    goose.goTo(document.querySelector('#summit'), { then: 'sit' });   // route: walk, drop, jump, climb
    goose.hideBehind(document.querySelector('.crate'));               // duck and peek
    goose.say('honk?');                                                // bubble at the beak
    goose.shoo();                                                      // startle and run
    clawd.perform('think');                                            // any animation of its own, in place
    goose.addEventListener('actorstate', (e) => console.log(e.detail.to));

    const stage = document.querySelector('pixel-stage');
    stage.pause();                // what the built-in button does; remembered
    stage.world.invalidate();     // after you move elements with CSS transforms

Characters need a few animations to do all this: a walk with a speed, jump, fall, climb, sit, duck and peek. Every figure has presets for them; see Figures and motions. The full reference is docs/stage.md.
