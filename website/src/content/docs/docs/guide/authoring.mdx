## Parts and shapes

Coordinates are units on a 100 × 100 canvas, y down. Parts hold shapes (`circle`, `ellipse`, `rect`, `capsule`, `polygon`) and rotate around their `pivot`; a part with a `parent` moves with it.

<SpecPlayground

  spec={`{

  "materials": {

  "parts": [
    {"id": "body", "pivot": [50, 90], "shapes": [

      {"type": "circle", "cx": 40, "cy": 60, "r": 3.2, "material": "eye"},
      {"type": "circle", "cx": 60, "cy": 60, "r": 3.2, "material": "eye"}
    ]}
  ],
  "animations": {

  }
}`}

Try: change the body colour, make the ellipse wider, or set the size to 16 px to see the icon render.

## Materials and textures

Materials give colour, texture (`noise fur scales stripes checker cloth bricks spots metal`), shine, and whether a shape is outlined. Textures stick to moving parts; small sizes simplify them automatically.

## Plug-ins: new shapes, textures and motions

A plug-in registers new building blocks; specs then use them like built-ins, with the same validation. This playground loads `examples/plugins/extras.mjs`, which adds a `star` shape, a `feathers` texture and a `float` motion.

```js
export default function setup({ registerShape, registerTexture, registerMotion }) {
  registerShape('star', { required: ['cx', 'cy', 'r'], keys: ['r2', 'tips', 'round', 'rot'], compile: (s) => ({ sdf, R, bbox }) });
  registerTexture('feathers', (x, y, scale) => brightness);
  registerMotion('float', { generate: ({ rig, params, samples }) => ({ tracks: { [rig.root]: { y: [...], rot: [...] } } }) });
}
// CLI: npx pixel preview starfish.json --plugin extras.mjs
```
