Click the goose: its bundle carries a small state machine, so it honks; hover it and it starts hacking.

## How it fits together

1.  **Write a character** as JSON: materials, parts with shapes, animations. Start from a figure (goose, human, dog, chibi, blob) and its motion models do the walking, jumping and climbing. [Writing a character](/docs/guide/authoring/)
2.  **Bake a bundle**: one JSON file with sprite sheets at 16, 32 and 64 px plus events, attachment points and the foot line. `npx pixel bundle goose.json`. [Bundles](/docs/guide/export/)
3.  **Play it** with `<pixel-sprite>`, drive it with a state machine, move it with the shared clock, or let it loose on the page with `<pixel-stage>`.
